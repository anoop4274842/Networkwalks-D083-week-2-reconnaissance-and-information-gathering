# Networkwalks-D083-week-2-reconnaissance-and-information-gathering
### 🔎 Reconnaissance & Information Gathering
This project documents a cybersecurity reconnaissance and information-gathering exercise conducted as part of a Week 2 project. The assessment demonstrates the use of Kali Linux tools to collect publicly available information, identify technologies and security mechanisms, enumerate DNS records, discover network hosts, and map infrastructure relationships.
### 🎯 Objectives
Perform domain and infrastructure reconnaissance
Gather publicly available information about a target
Identify web technologies and server configurations
Inspect HTTP response headers
Detect Web Application Firewall (WAF) presence
Enumerate DNS records
Perform network host discovery
Map infrastructure relationships
Collect information from public sources

### ⚙️ Reconnaissance Activities
1. Domain Registration – WHOIS
WHOIS was used to retrieve publicly available domain registration information.
2. Web Technology Fingerprinting – WhatWeb
WhatWeb was used to identify web technologies and server configuration information.
3. HTTP Header Inspection – cURL
cURL was used to inspect HTTP response headers returned by the target server.
4. WAF Detection – Wafw00f
Wafw00f was used to determine whether a Web Application Firewall was present.
5. DNS Enumeration – DNSRecon
DNSRecon was used to enumerate DNS records associated with the target domain.
6. Domain Resolution – Nslookup
Nslookup was used to resolve the target domain to its corresponding IP address.
7. Network Host Discovery – Zenmap
Zenmap, the graphical interface for Nmap, was used for host discovery across the local subnet.
8. Infrastructure Mapping – Maltego
Maltego was used to visually map relationships between infrastructure entities.
9. Public Source Harvesting – theHarvester
theHarvester was used to gather publicly available emails, subdomains, and host information.
### 📊 Findings
The reconnaissance exercise documented domain information, web technologies, HTTP information, WAF detection, DNS records, network hosts, infrastructure relationships, and information gathered from public sources. The report also documents an exposed webcam interface identified during the exercise.
